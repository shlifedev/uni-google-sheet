# HolySheet 사용자 문서

본문은 `src/content/docs/`의 Markdown 파일입니다. 폴더 하나가 사이드바의 묶음 하나입니다.

| 폴더 | 사이드바 묶음 | 내용 |
| --- | --- | --- |
| `index.md`, `start/` | 시작하기 | 개요, 설치, 첫 테이블 |
| `sheets/` | 시트 작성하기 | 시트 구조, 타입, 키와 참조, enum, 시트 나누기 |
| `tools/` | 도구 사용하기 | 창, 소스, Google Sheets, 문제 해결, 선택 빌드, 데스크톱 앱, 명령줄 |
| `runtime/` | 게임에서 사용하기 | 불러오기, 조회, 다시 불러오기, 변조 감지 |
| `reference/` | 참고 | `holysheet.json` 레퍼런스, 자주 겪는 문제 |

## 페이지 추가하기

해당 폴더에 `.md` 파일을 추가하면 사이드바에 나타납니다. 파일 상단의 `title`로 제목을, `sidebar.order`로 묶음 안의 순서를 지정합니다. 새 묶음을 만들려면 `astro.config.mjs`의 `sidebar`에 폴더를 추가합니다.

## 그림

- 화면 캡처는 `src/assets/screenshots/`에 있습니다. 예제 프로젝트 `MyGame`을 데스크톱 앱에서 한국어, 어두운 테마, 너비 940px로 연 화면입니다. 창의 구성이나 문구가 바뀌면 같은 조건으로 다시 찍습니다.
- 흐름도(`hs-flow`)와 스프레드시트 그림(`hs-sheet`)은 본문에 HTML로 적고, 모양은 `src/styles/theme.css`에 있습니다. 쓰는 방법은 그 파일의 주석에 있습니다.

## 쓰는 규칙

- 버튼과 메뉴 이름은 HolySheet 창에 표시되는 한국어 그대로, 굵게 적습니다(**전체 빌드**). 문구의 원본은 `src/Editor/HolySheetText.cs`입니다.
- 문제 메시지와 명령줄 출력은 영어 원문 그대로 적습니다.
- 코드 블록은 한 줄을 70자 안쪽으로 유지합니다. 본문 폭을 넘으면 가로로 스크롤됩니다.

## 미리 보기

Node.js 22.23.4 이상을 설치한 뒤 저장소 루트에서 실행하세요.

```sh
cd docs
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 열면 수정한 내용을 바로 확인할 수 있습니다. 검색까지 확인하려면 `npm run build` 후 `npm run preview`를 실행하세요.
