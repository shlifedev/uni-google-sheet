기본 설정에서는 시트 탭 이름이 테이블 이름이 됩니다. Excel과 Google Sheets에서는 탭 이름을 `Item`으로 지정하고, CSV 폴더를 읽을 때는 파일 이름을 `Item.csv`로 지정합니다.

## 타입과 필드 이름

첫 줄에 타입을 쓰고 바로 아래에 필드 이름을 적습니다. 셋째 줄에는 각 열의 용도를 적습니다. 아래 예시는 아이템을 번호로 찾거나 같은 등급끼리 모아 볼 수 있는 시트입니다.

| `Key<int>` | `string` | `Index<int>` | `float[]` |
| --- | --- | --- | --- |
| Id | Name | Tier | Stats |
| 아이템 번호 | 이름 | 등급 | 능력치 목록 |
| 1001 | 나무 검 | 1 | 3, 1.5 |
| 1002 | 가죽 갑옷 | 1 | 5 |

- **키**는 한 행을 찾을 때 씁니다. 위 시트에서 `tables.Item.Get(1001)`은 나무 검을 반환합니다. 같은 번호를 두 번 쓰면 검사에서 오류가 발생합니다.
- **인덱스**는 같은 값을 가진 행을 모을 때 씁니다. `tables.Item.ListByTier(1)`은 나무 검과 가죽 갑옷을 모두 반환합니다.
- **배열**은 한 셀에 여러 값을 담습니다. 나무 검의 `Stats[0]`은 `3`, `Stats[1]`은 `1.5`입니다. CSV를 직접 작성할 때는 쉼표가 든 셀을 `"3, 1.5"`처럼 큰따옴표로 감쌉니다.

## 작업 중인 데이터 제외하기

| 제외할 대상 | 작성 예 |
| --- | --- |
| 시트 전체 | 탭 이름을 `#기획메모`로 지정합니다. |
| 열 하나 | 해당 열의 첫 줄에 `#note`를 적습니다. |
| 행 하나 | 해당 행의 A열 값을 `~1002`로 바꿉니다. |

행을 다시 포함하려면 A열 값을 원래 키인 `1002`로 되돌린 뒤 빌드합니다.
