Unity의 HolySheet 창과 데스크톱 앱에서 같은 방법으로 Google Sheets를 연결할 수 있습니다. 팀 전용 문서는 서비스 계정에 뷰어 권한을 주고, 이미 공개한 예제 문서는 공개 링크로 연결하세요.

## 스프레드시트 추가하기

1. Google Sheets에서 읽을 시트를 엽니다. 탭 이름과 헤더 세 줄은 Excel과 같은 규칙을 사용합니다.
2. HolySheet의 **설정 → 소스 → 소스 추가**에서 **Google Sheets**를 선택합니다.
3. **스프레드시트** 칸에 문서 URL을 붙여넣습니다.

## 접근 방식 선택하기

| 문서 공유 상태 | HolySheet 설정 |
| --- | --- |
| 링크가 있는 모든 사용자가 볼 수 있는 문서 | **접근 방식 → 공개 링크**를 선택합니다. |
| 팀 전용 문서 | 문서를 서비스 계정 이메일에 **뷰어**로 공유합니다. **접근 방식 → 서비스 계정**을 선택하고 **키 파일**에 계정의 JSON 키 파일 경로를 지정합니다. |

서비스 계정 키 파일은 저장소 밖에 보관하세요. 설정을 마치면 **검사**를 눌러 연결을 확인하고, **전체 빌드**를 눌러 현재 시트 내용으로 C# 코드와 데이터를 생성합니다.

## 오프라인에서 다시 빌드하기

소스의 **스냅샷 폴더**에 `Snapshots/Items`처럼 저장할 경로를 지정합니다. 온라인에서 한 번 빌드하면 읽어 온 시트가 그 폴더에 CSV로 저장됩니다. 이후 **오프라인**을 켜고 빌드하면 마지막에 저장한 내용을 사용합니다. 최신 편집 내용을 받으려면 오프라인을 끄고 다시 빌드하세요.
