시트의 타입 행에는 그 열에 어떤 값이 들어가는지 적습니다. 타입에 맞지 않는 값은 [검사](../../tools/problems/)에서 오류로 알려 줍니다.

## 한눈에 보기

| 타입 칸에 쓰는 것 | 셀에 적는 값 | 설명 |
| --- | --- | --- |
| `int`, `long`, `float` 등 | `100`, `1.5` | [기본 타입](#기본-타입) |
| `string` | `나무 검` | 글자 |
| `bool` | `true`, `false` | 참·거짓 |
| `DateTime` | `2026-01-31` | [날짜와 시간](#날짜와-시간) |
| `int[]`, `string[]` | `1, 2, 3` | [배열](#배열) |
| `Enum<EItemKind>` | `Weapon` | [enum](../enums/). 정해진 선택지 중 하나 |
| `Key<int>` | `1001` | [키](../keys-and-refs/). 행을 찾는 고유한 값 |
| `Index<int>` | `1` | [인덱스](../keys-and-refs/#인덱스). 같은 값끼리 모아 보기 |
| `Ref<Item>` | `1001` | [참조](../keys-and-refs/#참조). 다른 테이블의 행 |
| `Mapping<EMonsterId>` | `Slime` | [매핑](../enums/#행에-이름-붙이기). 행에 코드용 이름 붙이기 |

## 기본 타입

C#의 타입 이름을 그대로 씁니다.

| 종류 | 타입 | 빈 셀의 값 |
| --- | --- | --- |
| 정수 | `byte` `sbyte` `short` `ushort` `int` `uint` `long` `ulong` | `0` |
| 소수 | `float` `double` | `0` |
| 글자 | `string` | 빈 문자열 |
| 참·거짓 | `bool` | `false` |

- 정수 열에는 소수점이나 천 단위 쉼표 없이 적습니다. `1,000`이 아니라 `1000`입니다.
- 소수점은 항상 마침표(`.`)입니다. 컴퓨터의 언어 설정과 상관없이 같은 결과가 나옵니다.
- `bool`은 `true`, `false`, `1`, `0`을 받습니다. 대소문자는 구분하지 않습니다.

## 날짜와 시간

`DateTime` 열에는 다음 형식 중 하나로 적습니다. 값은 UTC로 읽습니다.

| 셀 | 의미 |
| --- | --- |
| `2026-01-31` | 2026년 1월 31일 0시 |
| `2026-01-31 13:30:00` | 2026년 1월 31일 13시 30분 |
| `2026-01-31T13:30:00Z` | ISO 8601 형식 |

## 배열

타입 뒤에 `[]`를 붙이면 한 셀에 여러 값을 담습니다. 값은 쉼표로 구분하고, 대괄호는 써도 되고 안 써도 됩니다. 코드에서는 `item.Stats[0]`처럼 순서대로 꺼냅니다.

| 셀 | 들어가는 값 |
| --- | --- |
| `1, 2, 3` 또는 `[1, 2, 3]` | `1` · `2` · `3` |
| `sword, blade` | `sword` · `blade` |
| `"Hello, world", plain` | `Hello, world` · `plain` |
| 빈 셀 또는 `[]` | 빈 배열 |

- 값 앞뒤의 공백은 무시합니다.
- 값 안에 쉼표나 대괄호가 있으면 큰따옴표로 감쌉니다. 따옴표 안에서 큰따옴표 자체는 `\"`로 적습니다.
- `int[]`, `string[]`, `Enum<EItemKind>[]`, `Ref<Item>[]`처럼 어떤 타입에도 붙일 수 있습니다. 키와 인덱스는 배열로 만들 수 없습니다.

:::caution[배열에서 자주 하는 실수]
검사는 다음 두 경우를 경고로 알려 줍니다.

- **천 단위 쉼표가 표시된 숫자.** Google Sheets는 화면에 보이는 대로 값을 넘겨줍니다. `1000`을 `1,000`으로 표시하면 `1`과 `0` 두 값이 됩니다. 배열 열의 셀 서식을 **일반 텍스트**로 바꾸세요.
- **`|`로 구분한 값.** `sword|blade`는 값 하나로 읽습니다. `sword, blade`로 고치세요.
:::

### 같은 이름의 열을 배열로 묶기

값마다 칸을 따로 쓰고 싶으면 같은 타입, 같은 필드 이름의 열을 여러 개 둡니다. 왼쪽부터 차례로 배열 하나가 됩니다.

| `Key<int>` | `int` | `int` |
| --- | --- | --- |
| Id | Sockets | Sockets |
| 아이템 번호 | 소켓 | 소켓 |
| 1001 | 1 | 2 |

`item.Sockets`는 `1`, `2` 두 값을 가진 배열입니다.

### 구분자 바꾸기

쉼표 대신 다른 글자로 구분하려면 **설정 → 시트와 빌드 옵션 → 배열 구분자**를 바꿉니다. 예를 들어 `|`로 지정하면 `1|2|3`으로 적습니다. `[1, 2]` 형식과 큰따옴표는 구분자와 상관없이 쓸 수 있습니다.
