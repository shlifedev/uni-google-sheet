소스는 HolySheet가 시트를 읽어 오는 곳입니다. 한 프로젝트에 여러 소스를 둘 수 있고, 종류를 섞어도 됩니다. 어떤 소스에서 읽든 [시트 규칙](../../sheets/basics/)은 같습니다.

## 소스의 종류

| 종류 | 읽는 대상 | 워크북과 시트 |
| --- | --- | --- |
| **엑셀 워크북** | `.xlsx` 파일 하나, 또는 폴더 안의 모든 `.xlsx` | 파일이 워크북, 탭이 시트입니다. |
| **CSV 폴더** | `.csv` 파일이 든 폴더 | 폴더가 워크북, 파일 하나가 시트입니다. `Item.csv`가 `Item` 시트입니다. |
| **Google Sheets** | 스프레드시트 하나 | 스프레드시트가 워크북, 탭이 시트입니다. |
| **구글 드라이브 폴더** | 폴더 안의 모든 스프레드시트와 `.xlsx` | 파일마다 워크북 하나입니다. |

Google 소스는 접근 권한 설정이 필요합니다. [Google Sheets 연결하기](../google-sheets/)에서 따로 설명합니다.

## 소스 추가하기

1. **설정** 페이지를 엽니다.
2. **소스** 묶음에서 **소스 추가**를 누르고 종류를 고릅니다.
3. 새로 생긴 카드에 경로를 입력하거나 **찾아보기**로 고릅니다.
4. **검사**를 눌러 시트가 잘 읽히는지 확인합니다.

소스를 없애려면 카드 오른쪽 위의 제거 버튼을 누릅니다. 파일은 지워지지 않고 연결만 끊깁니다.

경로는 `holysheet.json`이 있는 폴더를 기준으로 적습니다. `Sheets`는 프로젝트 폴더 바로 아래의 `Sheets` 폴더입니다.

## Excel 워크북

`holysheet.json`을 처음 만들면 `Sheets` 폴더를 읽는 Excel 소스가 하나 들어 있습니다. 이 폴더에 `.xlsx` 파일을 넣기만 하면 됩니다.

- 폴더를 지정하면 그 안의 `.xlsx` 파일을 모두 읽습니다.
- Excel에서 파일을 열어 둔 채로 빌드해도 됩니다. 저장한 내용까지 반영됩니다.
- 셀 서식(색, 굵기, 열 너비)은 결과에 영향을 주지 않습니다. 보기 좋게 꾸며도 됩니다.

## CSV 폴더

스프레드시트 프로그램 없이 텍스트 편집기나 스크립트로 데이터를 만들 때 씁니다. 파일 이름이 시트 이름이므로 `Item.csv`, `Item.Weapons.csv`, `Game.Config.csv`, `Enums.csv`처럼 짓습니다.

```csv title="Sheets/Csv/Item.csv"
Key<int>,string,int,float[]
Id,Name,Price,Stats
아이템 번호,이름,가격,능력치 목록
1001,나무 검,100,"3, 1.5"
1002,가죽 갑옷,150,5
```

- 쉼표가 든 값은 큰따옴표로 감쌉니다. 배열 `3, 1.5`는 `"3, 1.5"`로 적습니다.
- 값 안의 큰따옴표는 두 번(`""`) 적습니다.
- 파일은 UTF-8로 저장합니다.

## 여러 소스를 함께 쓰기

소스를 여러 개 두면 모든 시트를 한데 모아 하나의 테이블 묶음으로 빌드합니다. 예를 들어 아이템과 몬스터는 Excel로, 팀이 함께 고치는 밸런스 수치는 Google Sheets로 관리할 수 있습니다.

- 테이블 이름은 모든 소스를 통틀어 겹치지 않아야 합니다.
- [나눠 적은 시트](../../sheets/splitting/)는 원래 테이블과 다른 소스에 있어도 됩니다.
- 다른 소스의 테이블을 `Ref<>`로 가리킬 수 있습니다.

## 빌드가 읽은 내용 확인하기

제외 규칙과 시트 나누기를 적용한 뒤의 테이블을 직접 보고 싶으면 **설정 → 출력 → 변환된 CSV**에 폴더를 지정하세요. 빌드할 때마다 테이블 하나가 CSV 파일 하나로 저장됩니다. 저장소에 올려 두면 시트가 어떻게 바뀌었는지 변경 내역으로 볼 수 있습니다.
